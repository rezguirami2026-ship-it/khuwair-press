# مطبعة الخوير — البدء مع Claude Code

## محتوى المجلد

| الملف | ما هو |
|---|---|
| `index.html` | النسخة الحالية من الأداة، وهي تعمل |
| `CLAUDE.md` | ذاكرة المشروع، يقرؤها Claude Code تلقائياً في كل جلسة |
| `PROMPT.md` | المهمة الكاملة ومراحل التطوير |

## خطوات البدء

1. **فك الضغط** في مجلد باسم `khuwair-press`.
2. **افتح الطرفية** داخل المجلد، ثم نفّذ:
   ```
   git init
   claude
   ```
3. **الصق هذا السطر** في Claude Code:
   ```
   اقرأ PROMPT.md و CLAUDE.md ثم ابدأ بعرض الخطة
   ```
4. **راجع الخطة** ووافق عليها، ثم تابع مرحلة بمرحلة.
   - راجع لقطات الشاشة في نهاية كل مرحلة قبل الانتقال إلى التالية.

## نصائح

- **تعديل الأولويات**: عدّل `PROMPT.md` بحرية قبل البدء. احذف ما لا تحتاجه، أو أضف أفكارك.
- **التعديلات الصغيرة**: يكفي أن تطلبها مباشرة. Claude Code يتذكر المشروع من `CLAUDE.md`.
- **النشر**: عند الانتهاء اطلب منه النشر على GitHub Pages، مثل منصة رامي ماث.
