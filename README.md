# مطبعة الخوير

أداة عربية لتصميم مطبوعات المدرسة: الشهادات، والإعلانات، والملصقات، والدعوات. تُخرج ملفات A4 جاهزة للطباعة.
إعداد أ. رامي الرزقي.

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `npm install` | تثبيت الحزم، مرة واحدة |
| `npm run dev` | تشغيل نسخة التطوير على المتصفح |
| `npm run build` | بناء النسختين في مجلد `dist/` |
| `npm test` | تشغيل الاختبارات (ابنِ أولاً) |
| `npm run test:update` | تحديث اللقطات المرجعية بعد تغيير بصري مقصود |

## نتيجة البناء

- **`dist/site/`**: موقع جاهز للنشر على GitHub Pages.
- **`dist/single/khuwair-press.html`**: ملف واحد يعمل دون إنترنت. يُنقل على فلاش أو يُرسل بالبريد، ثم يُفتح بالمتصفح.

## ملفات المشروع

- `src/`: الكود.
- `legacy/v1.html`: النسخة الأولى، وتبقى مرجعاً للمقارنة.
- `PROMPT.md`: المهمة ومراحل التطوير.
- `CLAUDE.md`: ذاكرة المشروع.
